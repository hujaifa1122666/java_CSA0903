## Project Overview
This repository contains the task-wise work for the CSA09 Java Assignment 1. The project models a campus multi-level parking facility using Java object-oriented programming.

## Folder Guide
- `Task01` – Problem analysis and complexity analysis
- `Task02` – Data representation
- `Task03` – Allocation algorithm and completed `ParkingFacility`
- `Task04` – Constructors and object creation
- `Task05` – Static members and object life cycle
- `Task06` – Inheritance and UML
- `Task07` – Method overriding and Object methods
- `Task08` – Polymorphism and completed `FeeDemo`
- `Task09` – Abstraction and interfaces
- `Task10` – Packages and encapsulation
- `Task11` – Original complete system, tests and results
- `Task12` – Extended design challenge, tests and results

## Compile and Run
Use Java 17 or later unless your faculty specifies another version.

Example for Task 03:
```bash
cd Task03
javac ParkingFacility.java
java ParkingFacility
```

Example for Task 08:
```bash
cd Task08
javac FeeDemo.java
java FeeDemo
```

For Tasks 11 and 12, compile the Java files in their respective `src` folders. See each task's README or instructions when implementation is added.
